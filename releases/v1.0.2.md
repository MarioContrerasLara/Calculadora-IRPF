## ✨ UI Improvements

### Mobile Responsiveness (All Tabs)
- **SS Tab**: 8-column table → 3 mobile-friendly tables (Trabajador/Empleador/Combinado)
- **IRPF Tab**: Mínimo personal table fits on mobile (`table-layout: auto`)
- **Mensual Tab**: 
  - View-toggle 5 buttons in one row (`calc(20% - 6px)`)
  - Chart responsive viewBox (same pixel bar height on all screens)
  - foreignObject bar numbers with overflow handling

### Visual Changes
- Tab icons: Shield, Document, Bar-Chart, Pie-Chart (SVG)
- Build tag removed from footer
- Dynamic SS legend (show/hide based on row types)
- Distribución text fills full width (removed 60ch max-width)
- Mínimo personal table: € removed from headers, footer alignment fixed
