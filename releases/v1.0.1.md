# 📦 Release v1.0.1 — Salary Adjustment Feature

**Release Date:** 5 April 2026  
**Status:** ✅ Production Ready  
**Previous Version:** v1.0.0

---

## 🎯 Summary

Adds salary adjustment capability — users can now model mid-year salary changes with automatic SS and IRPF recalculation.

---

## ✨ New Features

| Feature | Description | File |
|---------|-------------|------|
| Salary Adjustment | Multiple salary levels within single year | `js/app.js` |
| Date-based adjustments | Day/month precision for salary changes | `index.html` |
| SS auto-recalculation | Automatic recalc with adjusted salaries | `js/app.js` |
| IRPF recalculation | Based on total annual income | `js/app.js` |
| Monthly breakdown | Account for salary changes in monthly views | `js/app.js` |
